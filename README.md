# Angular Blog — CRUD Exercise

A blog management application built with **Angular, TypeScript, and Laravel REST API** to practice CRUD operations and frontend-backend integration.

## Features
- View and manage blog posts
- Create and edit posts
- Soft Delete, Restore, and Force Delete
- API integration using Angular HttpClient
- Form validation and error handling
- Pagination
- Reusable components and Angular Signals

## Tech Stack
- Angular & TypeScript
- Laravel REST API
- PHP & MySQL
- Bootstrap
- RxJS
